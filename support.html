Desktop Flow Support

Contact

Email: phlo@phlo.pl. Include your macOS version and the status shown in the app. Do not send private files, passwords or verification codes.

Start using Desktop Flow

Use one display. In Finder's Desktop menu, turn off Stacks and select Sort By → None. Open Desktop Flow Store and check “Finder Stacks are off”. The first time, use Allow Desktop Access and confirm the Desktop in the system picker. After that, the app remembers your access. Choose a corner and Rows or Columns, then turn on Arrange new Desktop icons. If macOS asks for Finder Automation permission, allow it to enable positioning.

Only new items are arranged. Changing direction does not move existing icons. You can move an icon yourself; later items can fill the space it leaves behind. To test placement, create a folder from a Finder window showing the Desktop.

Placement is off or paused

Read the status immediately below Arrange new Desktop icons. Select the actual system Desktop folder, use one display, and turn off Finder sorting and Stacks. Quit any other Desktop Flow edition before enabling this one. If macOS permission was revoked, check System Settings → Privacy & Security → Automation, then try again. No free space: free up a spot on the Desktop and click Check Again. Pending after dragging: release the mouse and click Check Again. The app does not detect Stacks. Before turning Stacks back on in Finder, uncheck “Finder Stacks are off” to stop arranging. The visible Dock and menu bar are excluded from placement. Display configuration changes pause arranging.

Stop or restart

Turn off Arrange new Desktop icons, or choose Quit from the grid icon in the menu bar. Existing icon positions stay where they are. After relaunch, your settings and folder selection are retained, but placement starts off for an explicit restart. This first version does not launch automatically at login.

Current scope

New file and folder icons on one display. Stacks, automatically sorted Desktops, newly mounted disk icons, multiple displays and saved layouts are not supported. If reporting a problem, include macOS version, number of displays, chosen layout, and the status message. Do not send private documents or full Desktop screenshots.
