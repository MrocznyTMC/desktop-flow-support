Desktop Flow Support

Contact

Email: phlo@phlo.pl. Include your macOS version and the status shown in the app. Do not send private files, passwords or verification codes.

Start using Desktop Flow

Use one display. In Finder's Desktop menu, turn off Stacks and select Sort By → None. Open Desktop Flow Store, choose your Desktop folder, choose a starting corner and Rows or Columns, then enable Custom placement. If macOS asks for Finder Automation permission, allow it to enable positioning.

Only new items are arranged. Changing direction does not move existing icons. You can move an icon yourself; later items can fill the space it leaves behind. To test placement, create a folder from a Finder window showing the Desktop.

Placement is off or paused

Read the status immediately below Custom placement. Select the actual system Desktop folder, use one display, and turn off Finder sorting and Stacks. Quit any other Desktop Flow edition before enabling this one. If macOS permission was revoked, check System Settings → Privacy & Security → Automation, then try again. No free space: reduce reserved margins or increase the available icon area. Pending after dragging: release the mouse and click Check Again. Stacks are checked automatically. If they are on, turn off Use Stacks in Finder and enable Custom placement again. If their state cannot be verified, placement stays paused; a macOS update or unavailable preference access may require an app update. The app does not assume that missing information means Stacks are off.

Dock, Stage Manager and widgets

The visible Dock and menu bar are excluded from available space. Use Icon area and spacing to reserve additional margins for widgets, Stage Manager or a Dock that hides automatically. These additional areas are not measured automatically. Enabling Stacks pauses custom placement. Resume explicitly after turning them off. Display configuration changes pause positioning; check the area before resuming.

Stop or restart

Turn off Custom placement, or choose Quit from the grid icon in the menu bar. Existing icon positions stay where they are. After relaunch, your settings and folder selection are retained, but placement starts off for an explicit restart. This first version does not launch automatically at login.

Current scope

New file and folder icons on one display. Stacks, automatically sorted Desktops, newly mounted disk icons, multiple displays and saved layouts are not supported. If reporting a problem, include macOS version, number of displays, chosen layout, and the status message. Do not send private documents or full Desktop screenshots.
